# Validation evidence

**Current release:** [v1-final/README.md](v1-final/README.md), with pinned source, native checks, browser review and public-download verification.

The remaining folders contain dated development, compatibility and release-candidate evidence. A successful historical report applies only to the source, artifacts and environment identified in that report; failed attempts are retained where they explain a constraint or correction.

Routine local checks write to ignored `dist/checks/`. Do not replace historical evidence with a new test run or commit generated credentials, private configuration, binaries or live provider payloads here.
