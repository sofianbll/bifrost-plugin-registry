# README screenshots

Two language-matched sets, generated by the Playwright `screenshots` config
(`ui/playwright.screenshots.config.ts`, `ui/e2e/screenshots.spec.ts`) on the disposable
synthetic fixture (`tests/ui-fixture`, loopback port 4174, admin token is a public QA
constant) serving the UI built from the checked-out source. Each README references its
own language:

- `en/` — English interface (the default since commit `d13ac01`), referenced by `README.md`.
- `fr/` — French interface (`?lang=fr` or the language toggle), referenced by `README.fr.md`.

The PNGs are the Playwright baselines: pull requests compare a fresh run against them
(`.github/workflows/e2e.yml`) and fail when the UI drifts. Rendering differs across
operating systems, so they are generated on Linux only (`ubuntu-24.04`, Playwright 1.63.0
Chromium). Never commit images captured on macOS or Windows.

To refresh them after an intended UI change, run the **E2E** workflow manually
(Actions, Run workflow) with `update-screenshots` enabled, download the `docs-images`
artifact, copy its `en/` and `fr/` folders here and commit them in their own commit.
The workflow never commits or opens a pull request itself.

## Confidentiality

Only the synthetic fixture data (Fixture Labs · QA models, synthetic-provider)
is visible, and the spec never opens a screen that could expose a key secret
(e.g. the reveal dialog). Look at regenerated images before committing them: no
secret, token, password, internal URL or private data may appear in any file.
